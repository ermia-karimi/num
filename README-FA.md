# Numix Android build (GitHub Actions)

این بسته دو نسخه مستقل را از آخرین سورس‌های ارسالی آماده می‌کند:

- `persian/` — شناسه برنامه `com.infinitycode.numix.fa`
- `international/` — شناسه برنامه `com.infinitycode.numix`

## راه‌اندازی

1. محتویات این پوشه را در ریشه یک GitHub repository قرار بده.
2. مطمئن شو شاخه اصلی repository نامش `main` است. اگر نام دیگری دارد، در فایل `.github/workflows/build-apks.yml` آن را تغییر بده.
3. کل پوشه‌ها و فایل‌ها را commit و push کن.
4. در GitHub وارد تب **Actions** شو.
5. workflow با نام **Build Numix APKs** را باز کن و **Run workflow** را بزن.
6. پس از پایان موفق هر دو job، در همان اجرای workflow بخش **Artifacts** دو خروجی می‌بینی:
   - `Numix-Persian-APK`
   - `Numix-International-APK`
7. هر Artifact را دانلود و از حالت ZIP خارج کن؛ فایل `app-debug.apk` داخل آن است.

## نکات مهم

- این workflow فعلاً APK آزمایشی (debug) می‌سازد؛ برای انتشار عمومی در فروشگاه‌ها باید نسخه release را با کلید امضای اختصاصی امضا کنیم.
- این دو شناسه برنامه متفاوت‌اند، پس امکان نصب هم‌زمان دو نسخه وجود دارد.
- محتوای خود بازی داخل APK بسته‌بندی می‌شود و اجرای هسته بازی به اینترنت وابسته نیست.
- تبلیغات همچنان از پنل GitHub Pages شما خوانده می‌شوند؛ بنابراین دریافت/نمایش تبلیغ به اینترنت نیاز دارد.
- تغییرات HTML/CSS/JS پس از ساخت APK جدید، برای ورود به APK باید دوباره workflow اجرا و APK جدید نصب شود. فایل‌های تبلیغ پنل، چون آنلاین هستند، بدون ساخت مجدد APK قابل تغییرند.
- آیکون پیش‌فرض Capacitor فعلاً استفاده می‌شود. قبل از انتشار نهایی باید آیکون Numix را در قالب منابع Android جایگزین کنیم.
- این بسته فقط سورس و workflow ساخت را آماده می‌کند؛ APK نهایی پس از push شدن به GitHub و اجرای workflow ساخته خواهد شد.
